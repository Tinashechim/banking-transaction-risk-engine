\# Banking Transaction \& Risk Engine



A portfolio-grade banking backend designed to demonstrate relational database engineering, transaction processing, concurrency control, security, auditing, and transaction risk management.



\## Project Objectives



The system will provide backend functionality for:



\- Customers

\- Accounts

\- Transactions

\- Transfers

\- Beneficiaries

\- Loans

\- Loan payments

\- Interest rates

\- Audit logs

\- Risk rules



\## Database Engineering Demonstrations



The project will demonstrate:



\- ACID transactions

\- Concurrent transfers

\- Transaction isolation levels

\- Row-level locking

\- Transaction rollback

\- Deadlock handling

\- Stored procedures

\- Database indexing

\- Audit trails

\- Role-based security

\- Transaction history



\## Concurrency Demonstration



A major objective of the project is to simulate simultaneous transactions against the same bank account and demonstrate that the database maintains correct account balances under concurrent access.
